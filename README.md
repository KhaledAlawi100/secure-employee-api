# Secure Employee API

A production-style Spring Boot REST API built to demonstrate modern Spring Security concepts.

## Tech Stack

- Java 21
- Spring Boot 4
- Spring Security
- Spring Data JPA
- PostgreSQL
- Docker
- Docker Compose
- Lombok
- JWT
- OAuth2 / OpenID Connect

## Features

- User registration
- Secure password hashing
- JWT authentication
- Refresh tokens
- Role-based authorization
- Permission-based authorization
- Method-level security
- OAuth2 / OpenID Connect
- CORS
- CSRF
- Stateless authentication
- Production security practices
